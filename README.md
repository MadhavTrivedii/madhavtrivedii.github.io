# madhavtrivedi.github.io

Personal portfolio of Madhav Trivedi. Plain HTML and CSS, with no build step.

## Deploy on GitHub Pages

1. On GitHub, create a free organisation named `madhavtrivedi` (your profile picture menu, then Your organizations, then New organization, then the Free plan).
2. Inside that organisation, create a public repository named exactly `madhavtrivedi.github.io`.
3. Upload `index.html`, `resume.pdf` and `.nojekyll` to the repository root, then commit.
4. In the repository, open Settings, then Pages. Set the source to "Deploy from a branch", choose `main` and `/ (root)`, then save.
5. After a minute or two the site is live at https://madhavtrivedi.github.io

## Updating

- Résumé: replace `resume.pdf` with a file of the same name.
- Project links: each "View source" link in `index.html` points to github.com/MadhavRaiTrivedi. Change each one to its repository URL.
- Accent colour: change `--accent` near the top of `index.html`.
