# madhavtrivedii.github.io

Personal portfolio of Madhav Trivedi. Plain HTML and CSS, with no build step.

Live at https://madhavtrivedii.github.io

## Deploy

GitHub Pages serves the `main` branch from the repository root. Pushing to `main` redeploys the site within a minute or two. `.nojekyll` stops Pages from running the files through Jekyll.

## Updating

- Résumé: replace `resume.pdf` with a file of the same name.
- Accent colour: change `--accent` near the top of `index.html`.
